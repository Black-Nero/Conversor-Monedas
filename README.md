## Guía para usar el conversor de divisas

**Para usar este conversor de divisas, necesitas:**

* **Java 8 o una versión más reciente.**
* **La biblioteca Gson para manejar archivos JSON.**
* **Una clave de API de ExchangeRate-API.**

**Instalación:**

1. **Descarga los archivos del proyecto o clona el repositorio.**
2. **Añade la biblioteca Gson al proyecto.**
3. **Reemplaza "YOUR-API-KEY" en la clase "API" con tu propia clave de API de ExchangeRate-API.**

**Estructura del proyecto:**

El proyecto está dividido en cuatro partes:

* **API:** Se encarga de comunicarse con la API de ExchangeRate-API y obtener la información en formato JSON.
* **ConversorDivisas:** Contiene la lógica para convertir las divisas.
* **Menu:** Permite al usuario interactuar con el programa a través de la terminal.
* **Main:** Es el punto de partida del programa.

**Uso:**

1. **Ejecuta la clase "Main".**
2. **El programa mostrará las divisas que puedes convertir.**
3. **Introduce la divisa de origen, la divisa de destino y la cantidad que quieres convertir.**
4. **El programa te mostrará el resultado de la conversión.**
